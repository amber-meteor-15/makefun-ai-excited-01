FIRST LIGHT — a deterministic TypeScript program that procedurally draws a universe being born from a single seed: a golden seed cracks open on dark soil, a sprout and a beam of light rise from it, and the beam blooms into a glowing spiral galaxy with ringed planets, while veins of light mirror the galaxy beneath the ground. Pure Node standard library, fixed-seed, byte-identical output on every run.

## Run it

```sh
npx tsx main.ts
```

Writes `entry.png` (1024×1024) to `$MAKEFUN_OUTPUT_DIR` or `/output`.
